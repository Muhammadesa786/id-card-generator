# 🎫 Professional ID Card Generator

A modern, responsive web application for creating professional ID cards with multiple templates, digital signatures, and mobile-first design.

## ✨ Features

### 🎨 Multiple Professional Templates
- **Butterfly Wings** - Classic design with light blue and red accents
- **Geometric Blue** - Premium modern design
- **Red & Black Geometric** - Bold contemporary style
- 6+ additional templates to choose from

### 📱 Mobile-First Design
- **Hamburger Menu** - Slide-out control panel on mobile
- **Sticky Action Bar** - Quick access to download and print buttons
- **Fluid Scaling** - ID cards automatically resize for any screen
- **Touch-Optimized** - All inputs and buttons sized for comfortable mobile use

### 🖼️ Advanced Photo Features
- **Smart Cropping** - Automatic face-focused positioning
- **Enhanced Clarity** - Contrast and brightness optimization
- **Professional Framing** - Clean borders with elegant shadows

### ✍️ Digital Signatures
- **Draw Signatures** - Built-in signature pad for both student and principal
- **Auto-Sign** - Default signature option for principals
- **Secure Storage** - Signatures saved with the card data

### 💾 Data Persistence
- **Auto-Save** - Form data automatically saved to browser storage
- **No Data Loss** - Refresh the page without losing your work

### 🎯 Professional Features
- **QR Code Generation** - Automatic QR codes for verification
- **Customizable Labels** - Modify field labels to match your needs
- **Color Matching** - Auto-extract colors from your logo
- **Print Ready** - A4 print preview and quick print options

## 🚀 Installation

1. Clone the repository:
```bash
git clone https://github.com/YOUR_USERNAME/id-card-generator.git
cd id-card-generator
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser to `http://localhost:5173`

## 📦 Build for Production

```bash
npm run build
```

The production-ready files will be in the `dist` folder.

## 🛠️ Technologies Used

- **React** - UI framework
- **Vite** - Build tool and dev server
- **Lucide React** - Icon library
- **html-to-image** - Export ID cards as images
- **react-signature-canvas** - Digital signature capture
- **qrcode.react** - QR code generation
