# 🚀 Vercel Deployment - Quick Reference

## Your Repository
**GitHub URL**: https://github.com/Muhammadesa786/id-card-generator

## Step 1: Sign Up/Login
- URL: https://vercel.com/signup
- Click: **"Continue with GitHub"**
- Authorize Vercel to access your GitHub

## Step 2: Import Project
- Click: **"Add New..."** → **"Project"**
- Find: **"id-card-generator"**
- Click: **"Import"**

## Step 3: Configure (Auto-detected)
✅ Framework Preset: **Vite**
✅ Build Command: `npm run build`
✅ Output Directory: `dist`
✅ Install Command: `npm install`

**No changes needed - just verify these are set!**

## Step 4: Deploy
- Click: **"Deploy"** button
- Wait: 1-2 minutes
- Success: You'll get a live URL!

## Your Live URL
After deployment, you'll get something like:
`https://id-card-generator-xxx.vercel.app`

## Auto-Updates
Every `git push` to GitHub = automatic redeployment! 🎉
